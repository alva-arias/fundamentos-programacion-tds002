# NOTAS

## Diferencia entre int y double

`int` se utiliza para almacenar números enteros, es decir, números que no tienen decimales. 

`double` se utiliza para almacenar números que pueden tener decimales. 
## ¿Qué es el casting?

El casting es convertir un dato de un tipo a otro. Se utiliza cuando necesitamos trabajar un valor como otro tipo de dato.

Por ejemplo, podemos convertir un `double` a `int`:

```csharp
double numero = 10.5;
int entero = (int)numero
